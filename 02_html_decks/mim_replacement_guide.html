MIM移行プロジェクト工程

Phase 4 移行・カットオーバー2〜4ヶ月並行稼働検証。MIMからの段階切り替え。ユーザー教育。MIM廃止。

先行移行できる機能（今すぐ実施推奨）

✅ MIM SSPR → Entra ID SSPR（今すぐ移行可能）

MIMのSSPR（Self-Service Password Reset）機能はEntra ID SSPRで完全に代替できます。Entra ID SSPRはモバイルMFAでの確認・秘密の質問・メール確認をサポート。

移行工数: 1〜2人月。即効性: 高（ヘルプデスクのパスワードリセット問合せを80%削減）。

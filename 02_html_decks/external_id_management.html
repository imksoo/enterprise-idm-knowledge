🌐 外部ID管理ガイド

代理店・協力会社・外部ベンダーのID管理設計 | 2026-04-07 | NSSOL IDM参照資料

外部IDとは： 自社の正規従業員ではないが、社内システムへのアクセスが必要な人物のIDです。 代理店（損保・銀行）、協力会社作業員（建設・製造）、外部委託ベンダー（ITシステム保守）、派遣社員、インターンが該当します。 外部IDは正規IDの2〜10倍存在する企業も多く、ガバナンス上の最大リスクエリアです。

外部IDの主な種類と特性

種類例アクセス先主なリスク推奨管理方式
代理店・販売パートナー銀行代理店、保険代理店、SaaS再販パートナー販売管理・CRM・申請ポータル退職担当者のID残留。代理店休業後のID放置。代理店セルフ管理ポータル。有効期限必須。
協力会社・下請け作業員建設現場作業員、製造ライン派遣、ITシステム保守現場入退場、保守システム、PAM経由接続入れ替わりが激しく退職者IDが残る。資格期限切れでの作業。PAM Proxyでセッション管理。資格有効期限連動。
ITベンダー・委託先サーバー保守、開発委託、セキュリティMSS管理コンソール、サーバーSSH/RDP、DevOps環境共有アカウント使用。作業後のID放置。作業ログなし。PAMで個人ID化+セッション録画。作業前後の自動有効期限。

外部ID管理の推奨アーキテクチャ

🏛️ 基本設計思想：「自社認証基盤を外部IDに広げない」

外部ユーザーに自社ADアカウントを発行することは避けます。理由：外部ID経由での侵害が自社AD全体に波及するリスクがあるためです。

推奨アーキテクチャ： 外部ユーザー専用の認証基盤（Entra External ID / B2B / ゲストアカウント）を設置し、外部IDからはアプリケーション層のみアクセス可能とします。内部ADへの直接経路は遮断します。

✅ Microsoft Entra External ID（推奨）

  • 外部ユーザーは自社のGoogleアカウント等を使ってEntraにB2Bゲストとして参加
  • 自社システムのSAML/OIDCアプリには条件付きアクセスでMFA強制
  • 有効期限・アクセス範囲の細かい制御
  • Entra Access Reviewで定期棚卸し自動化

🏗️ ITベンダー向けPAM Proxy

  • 外部ベンダーはPAMポータルにIDでログイン
  • PAMからサーバーへのSSH/RDPをProxy接続（認証情報は非開示）
  • 全セッションを録画・キーログ記録
  • 作業前後でPAMが自動でID有効・無効切り替え

📋 エグゼクティブサマリー

現状のID管理基盤が抱えるリスクと、今後3年間の近代化シナリオを経営視点で整理
多くの日本企業において、Active Directory を中心とした ID 管理基盤は設計から10〜15年が経過し、クラウド化・ゼロトラスト対応が遅れています。 2025〜2029年にかけて Windows Server / MIM 2016 の EOL が集中し、セキュリティインシデント・コンプライアンス違反・運用コスト増大の三重リスクが顕在化します。 本資料では現状の客観評価から投資判断フレームまでを15分で経営層にご説明します。

⚠ Section 2: 経営リスク3選

ID管理の放置が招く3大リスク — 定量根拠と国内事例を交えて説明

🔴 リスク①：ランサムウェアによる業務停止

平均復旧コスト
約2.3億円

Active Directory の特権アカウントが侵害された場合、攻撃者はドメイン全域に横展開し、バックアップも含めて暗号化するランサムウェア攻撃（Double Extortion）を展開します。多くの事例で業務停止期間は2〜6週間に及びます。

国内製造業A社（2023年）: サプライヤーのVPN接続経由でActive Directory管理者アカウントが侵害。生産管理・ERPシステムが全停止し、復旧まで約34日、損失額は推定30億円超。根本原因はMFA未適用・特権アカウントの棚卸し未実施。
世界統計（Veeam 2024 Data Protection Report）: ランサムウェアを受けた組織の93%がActive Directoryを標的にされたと報告。平均身代金要求額は1.54M USD（約2.3億円）、身代金支払い後も28%のデータは復元不可。
対策必須 MFA全員適用 → 特権アカウントPAM管理 → Tierモデル実装 → DR訓練

🟡 リスク②：内部不正・アクセス権放置による情報漏洩

退職者アカウント
平均95日残存

退職・異動後のアカウント放置、過剰権限の累積、ロールの棚卸し未実施は、内部不正と外部攻撃者の利用の両方のリスクを高めます。個人情報保護法改正・サイバーセキュリティ基本法の厳格化により、監査指摘・課徴金リスクも増加しています。

国内流通業B社（2024年）: 退職した元ITアウトソース担当者のアカウントが退職後8か月間有効のまま残存。当該アカウントで社内システムへの不正アクセスが発覚。個人情報約12万件が流出し、行政指導・損害賠償訴訟が発生。
統計（IPA「情報セキュリティ10大脅威 2025」）: 退職者アカウントの平均残存期間は95日。SaaS・クラウドへのアクセス権は見落とされがちで、退職者の22%が退職後もSaaSへアクセス可能な状態。
高優先度 IGA（Identity Governance）導入 → ジョイナー/ムーバー/リーバー自動化 → 定期認定サイクル

🟣 リスク③：EOL製品によるコンプライアンス違反・調達不能

ESU費用
最大3倍増

Windows Server 2019 EOL（2029年1月）、MIM 2016 EOL（2026年7月）など、ID管理基盤の主要コンポーネントのサポート終了が集中します。EOL後の継続使用はセキュリティパッチなし・ESU費用増大・PCI DSS/ISMS監査での不適合指摘に直結します。

ESU（延長セキュリティ更新プログラム）費用：Windows Server 2019 の ESU は、Year 1で通常ライセンス費の75%相当の追加費用、Year 2で100%、Year 3で125%と逓増します。オンプレミス環境では3年間でライセンス総費用が実質3倍以上になる試算もあります。
MIM 2016 EOL（2026年7月14日）: Microsoft Identity Manager 2016 はすでに一般サポート終了（2021年）。延長サポート終了後、プロビジョニング・パスワードリセット機能にパッチが提供されなくなります。代替はMicrosoft Entra ID GovernanceまたはSaviynt・SailPoint等のIGA製品への移行。
期限あり EOLロードマップ確認 → 移行計画策定（2025年中） → 移行実施（〜2028年）

🏢 Section 5: 他社事例4件

金融・製造・流通・医療 — 課題→対策→効果のカード形式（匿名）

🏭 金融業 A社

地方銀行 / 従業員1,800名 / FISC対応必須
課題
Active Directory の特権アカウントが40名超存在し、棚卸しが3年未実施。FISC安全対策基準の特権管理要件に非適合との内部監査指摘。
対策
CyberArk Privilege Cloud 導入。全Domain Admin を CyberArk 経由のジャストインタイム昇格へ移行。Entra ID P2 の PIM（Privileged Identity Management）と連携。
効果
常設特権アカウントをゼロに削減。特権操作の全セッション録画を実現。次回FISC監査で特権管理要件を完全適合と評価。ヘルプデスク工数30%削減。

🏭 製造業 B社

自動車部品メーカー / 従業員5,200名 / グローバル拠点あり
課題
海外拠点との VPN 接続で MFA 未適用。2022年にサプライヤー経由のランサムウェア被害で工場停止8日間、損失推定5億円。
対策
Entra ID P2 へ移行・条件付きアクセス全社適用。海外拠点を Entra Hybrid Join へ段階展開。Microsoft Sentinel でOT/IT境界の異常検知を実装。
効果
MFA適用率100%達成（12ヶ月）。フィッシング被害件数94%減少。Microsoft Sentinel で不審なラテラルムーブメントを自動検知・遮断する仕組みを確立。

🏭 流通業 C社

大手小売チェーン / 従業員8,000名 / 店舗PC多数
課題
MIM 2016 を使用したプロビジョニングが EOL直前。店舗スタッフの入退社処理に平均3.2日かかり、退職者アカウントが平均120日残存。
対策
MIM 2016 から Saviynt へ移行。人事システム（SAP HCM）との自動連携でジョイナー/ムーバー/リーバーを自動プロビジョニング化。
効果
プロビジョニング処理時間が3.2日から2時間以内に短縮。退職者アカウント残存ゼロを実現。IT部門の入退社対応工数を年間1,200時間削減。

🏭 医療機関 D社

大学病院 / 職員3,500名 / ISMS・医療情報ガイドライン対応
課題
電子カルテシステムへの共有アカウント運用が横行。個人情報保護法改正・厚生労働省「医療情報システムの安全管理ガイドライン第6.0版」への対応が未完了。
対策
Entra ID + FIDO2 セキュリティキーによるパスワードレス認証を電子カルテへ適用。Red Hat IdM で Linux 系医療機器の認証を統合。PKI 証明書による医師・看護師の個人認証基盤を構築。
效果
共有アカウント完全撲滅。医療情報ガイドライン第6.0版の個人認証要件に完全適合。ログイン操作時間が平均40%短縮（IC カードリーダーレス化）。

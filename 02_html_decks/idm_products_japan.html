🗺 日本市場 IDM製品カテゴリマップ

8カテゴリの概要・市場特性・日本での採用実態を俯瞰する
日本企業のIDM（Identity Management）製品は大きく8カテゴリに分類される。オンプレミスのActive Directory依存が根強い一方、 Microsoft 365普及に伴いEntra IDが急速にクラウドIdPとして浸透している。PAMは金融・製造の規制業種から導入が進み、 IGA（Identity Governance）は欧米比で普及が遅れているが、J-SOX・内部統制対応を機に導入機運が高まっている。
🏗 ディレクトリサービス AD DS / Entra ID / RHDS 採用率：非常に高い
🔑 IdP / SSO Entra ID / Okta / HENNGE 採用率：高い
🔒 PAM 特権管理 CyberArk / Delinea / SecureCube 採用率：中（規制業種中心）
🏛 IGA ガバナンス SailPoint / Saviynt / Entra Gov 採用率：低〜中（増加中）
📱 MFA / 認証デバイス Authenticator / YubiKey / NetAttest 採用率：高い
📡 MDM / UEM Intune / Jamf / SKYSEA 採用率：高い
☁ CASB / SASE Defender for Cloud Apps / Netskope 採用率：中（急成長）
🔭 SIEM + IDM連携 Sentinel / Splunk / QRadar 採用率：中

📦 8カテゴリ 日本市場特性詳細

🏗 ディレクトリサービス

オンプレミスのIDマスターはActive Directory DSが推定70%以上を占める。Windows Serverと グループポリシーの既存資産が厚く、即時廃止が難しい。クラウド側の実運用ディレクトリは Microsoft Entra IDがM365同梱で最大シェアを持つ。 Linux系環境ではRed Hat IdM（FreeIPA）またはRHDSが選択肢。 OpenLDAPはRHEL 8以降でサーバーパッケージが廃止されたため、新規標準には採りにくい。

AD 70%以上 Entra ID 急成長 OpenLDAP 注意

🔑 IdP / SSO

M365標準のEntra IDがデファクト基盤。マルチクラウドや非Microsoft中心環境ではOkta、 日本語サポート特化ではHENNGE One（国内IDaaS市場シェア4年連続1位）、中小規模では GMO TrustLogin（無料プランあり）やCloudGate UNOが実績を持つ。 オンプレミス連携が複雑な場合はPing Identity（PingFederate）が選択肢になる。

Entra ID デファクト HENNGE 国内No.1 Okta マルチクラウド

🔒 PAM 特権アクセス管理

金融・証券・上場製造での導入が先行。CyberArkが国内金融での実績最多で大手SIer対応も厚い。 Delinea（旧Thycotic/Centrify）はCyberArkより導入しやすい選択肢として中堅企業で採用が増加。 国産ではSecureCube Access CheckがFISC・J-SOX対応の実績を持つ。 Microsoft Entra PIM + LAPS を組み合わせることでコスト抑制しながら段階的PAMを構成できる。

CyberArk 金融標準 Delinea 中堅向き SecureCube 国産

🏛 IGA Identity Governance

J-SOX強化・内部統制・棚卸要件を機に関心が高まっている。SailPoint IdentityNow/IQが 証券・金融の大規模案件で最もよく名前が挙がる。SaviyntはSAP/ERP文脈のSoD説明に強い。 Entra ID GovernanceはMicrosoft中心環境での短期立ち上げに向く。 日本企業の複雑な例外承認ワークフローはOne Identity Managerが吸収しやすい。

SailPoint 定番 Saviynt ERP統制 Entra Gov 短期導入

📱 MFA / 認証デバイス

IdP組み込みMFAが普及の主流。独立型ではCisco Duoが既存VPN/ADを変えずに認証強化でき、 製造・流通での採用が多い。ハードウェアトークンはYubico YubiKey（FIDO2）が標準的。 ネットワーク認証ではSoliton NetAttest EPSが国内RADIUS証明書認証シェアNo.1（富士キメラ総研2025）。 生体認証ではFujitsu PalmSecure（手のひら静脈）、NEC NeoFace（顔認証）が国産実績。

Duo VPN強化 YubiKey FIDO2 NetAttest 国内No.1

📡 MDM / UEM

Windows端末はMicrosoft IntuneがEntra IDとの条件付きアクセスポリシーと連動し、 Entra Hybrid JoinまたはEntra Joinで統合管理するケースが急増。macOS・iOS中心はJamf。 国産ではSKYSEA Client Viewが資産管理・操作ログ用途で広く使われる。 ただし資産管理ツールはUEMとは設計思想が異なるため混同に注意。

Intune Windows標準 Jamf macOS SKYSEA 国産

☁ CASB / SASE

リモートワーク・SaaS多用化でCASB/SASEの需要が急成長。Microsoft Defender for Cloud Appsが M365利用企業に組み込まれる形で普及。専業ではNetskope・Zscalerが採用される。 IDMとの統合ポイントは「誰が・何に・いつアクセスしたか」の可視化で、SIEMとの連携設計が重要。

Defender M365同梱 Netskope 急成長

🔭 SIEM + IDM連携

IDログのSIEM連携は証跡保全とインシデント対応に不可欠。Microsoft SentinelはEntra IDとの ネイティブ連携が最も深く、条件付きアクセス違反・不審なサインインを自動検出できる。 Splunkはマルチベンダー環境での採用が多い。 SIEMへの送出は「診断設定 → Log Analytics → Sentinel」のパターンが一般的。

Sentinel Entra連携 Splunk マルチベンダー

🔧 Tierモデルによる特権分離設計

Tier 0 — ドメインコントローラ・Entra ID（最高権限）

AD/Entra ID管理者、Schema Admin、DCのローカル管理者。PAW（特権アクセスワークステーション）からのみアクセス可。MFA必須。緊急時のBreak Glass Accountを別途管理。

Tier 1 — サーバーOS管理者

Windows Server / RHEL の管理者アカウント。PAM経由必須。JEA（Just Enough Administration）でコマンド制限。セッション録画必須。

Tier 2 — エンドユーザーワークステーション

PC管理者。LAPSで自動パスワードローテーション。標準ユーザーへの権限最小化（UAC標準）。

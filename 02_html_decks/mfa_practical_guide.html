「スマホがない社員はどうするの？」に答える ― ユーザータイプ別の現実的MFA設計

MFAとは何か（30秒で説明）

通常のログインは「IDとパスワード」の2つで認証します。パスワードは盗まれることがあります。

MFA（多要素認証）は「パスワード＋もう一つの確認」を求める仕組みです。スマホへのコード送信が最も一般的ですが、スマホ以外の方法もあります。

なぜMFAが重要か：パスワードが盗まれても、スマホや物理キーがなければログインできません。フィッシング・不正ログインを防ぐ最も効果的な対策で、MFAを導入するだけで不正ログインを99%以上防げます（Microsoft調査）。

主要MFA方式の比較

📱

認証アプリ（Microsoft Authenticator / Google Authenticator）

スマホにアプリを入れて、ログイン時に6桁のコードを入力。または「承認」ボタンを押す（Authenticator App）。

設定：簡単 費用：無料 対象：スマホを使える社員・在宅勤務者
💳

ICカード・社員証タッチ認証（FIDO2/スマートカード）

社員証やICカードをパソコンのリーダーにかざしてMFA完了。スマホ不要。

設定：中程度 費用：リーダー1台3000〜8000円 対象：スマホなし社員・高齢者・工場・店舗スタッフ
🔑

ハードウェアセキュリティキー（YubiKey等）

USBに差し込むかNFCでタッチするだけでMFA完了。フィッシング耐性が最も高い。

設定：簡単（タッチのみ） 費用：1本3000〜8000円 対象：セキュリティ要件の高い役員・管理者・リモート勤務者
📍

信頼ネットワークからはMFA免除（条件付きアクセス）

会社のWi-Fi・LAN内からのアクセスはMFA不要。社外からのアクセス時のみMFAを求める。

設定：IT管理者が設定 費用：Entra ID P1ライセンス必要 対象：在宅勤務しない工場勤務者・店舗専用端末
📞

SMS・音声通話（最終手段）

登録した携帯電話にSMSまたは音声でコードを通知。ガラケーでも対応可能。

セキュリティ：低（推奨しない） 費用：通信費 対象：他の方法が使えない場合の最終手段のみ

ユーザータイプ別の推奨MFA方式

💼 オフィス社員
（在宅あり）
→
認証アプリ（Authenticator）
スマホを持っており設定も簡単。最もセキュアで費用ゼロ
🏭 工場・現場作業員
（スマホ持ち込み禁止）
→
ICカード（社員証）タッチ + 社内ネットワーク条件
スマホ持ち込み禁止でも社員証で対応。社内LANからの接続はMFA免除可
🛒 店舗パート
（60代・スマホなし）
→
店舗端末 + 信頼ネットワーク条件 または ICカード
店舗の固定端末からのアクセスはMFA免除。社外アクセスは発生しない設計
👑 役員・経営層
→
YubiKey（ハードウェアキー）+ 認証アプリ
高権限アカウントはフィッシング耐性最高のFIDO2キーを必須化
🏗️ 外部委託業者
→
認証アプリ必須（例外なし）
外部アクセスは最大リスク。スマホがない業者とは取引条件の見直しを検討
🖥️ システム管理者
（特権アカウント）
→
YubiKey + PAM踏み台経由を強制
管理者権限は最も危険。MFAに加えて作業録画も必須

全社MFA導入の手順（6ヶ月計画）

時期対象方法注意点
第1ヶ月 IT管理者・情報システム部門（先行） 認証アプリ設定 自分たちで試して問題を洗い出す
第2〜3ヶ月 役員・管理職 YubiKeyまたは認証アプリ 役員への個別サポートを用意
第3〜4ヶ月 オフィス社員全員 認証アプリ 設定ヘルプデスクの増員・FAQ整備
第5〜6ヶ月 現場・パート・外部業者 ICカード / 条件付きアクセス ユーザータイプ別の例外設計を事前に完成させる
💡 よくある失敗パターン：全員一斉に「来月からMFA必須」と通知すると、設定できない社員が続出してヘルプデスクがパンクします。必ず段階的な展開を計画してください。

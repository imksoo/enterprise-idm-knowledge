📋 導入時のチェックリスト
  1. HR側の確認：入退社情報の更新タイミング・データ品質・APIまたはファイル連携可否
  2. 権限設計：部門×役職×システムのロールマトリクス作成（これが最難関）
  3. 例外処理設計：派遣・業務委託・パート・兼務の扱い
  4. 緊急停止フロー：懲戒解雇・不正疑いの場合の即時停止手順
  5. 移行計画：既存の手作業フローとの切り替え方法
  6. テスト・UAT：HRとITが共同でシナリオテスト（入社・異動・退職各100件）

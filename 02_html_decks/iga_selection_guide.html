📋 IGA製品選定ガイド

Identity Governance & Administration — SailPoint / Saviynt / One Identity / Omada / Entra ID Governance | 2026-04-07

IGAが必要な理由： 従業員が増減・異動するたびに手動でIDを管理する従来手法は、 「退職者IDの放置（幽霊アカウント）」「過剰権限の蓄積」「棚卸しの工数爆発」という3大問題を引き起こします。 IGAはID管理を自動化し、ガバナンス証跡を自動生成します。

選定フローチャート

質問1: SAP環境でSOD管理が最重要ですか？

→ Yes Saviynt または One Identity（SAP Module）を優先検討
→ No 次の質問へ

質問2: Microsoft 365 / Azure が中心環境ですか？

→ Yes Microsoft Entra ID Governance（追加コスト最小）が最有力
→ No 次の質問へ

質問3: FISC対応で国産サポートが必須ですか？（地銀・保険）

→ Yes One Identity Manager（国内SI対応）が現実解
→ No 次の質問へ

質問4: グローバル対応・高度AIガバナンスが必要ですか？

→ Yes SailPoint Identity Security Cloud（グローバルシェア1位）
→ 中規模・コスト重視 Omada または Entra Governance

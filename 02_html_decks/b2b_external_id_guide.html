🏗️ B2B認証パターン3選

パターンA: 相手企業のIdPとフェデレーション（推奨: 大手取引先）

相手企業がEntra ID / Okta / 独自SAML IdPを持っている場合、自社システムとフェデレーション（信頼関係）を設定します。相手企業の認証（MFA含む）をそのまま利用できます。メンテナンスは最小。

適用例：大手スーパー→食品メーカー（大手の場合）、製造業→大手部品メーカー

パターンB: 自社がIdPを提供（推奨: 中小取引先）

自社がEntra External ID（旧Azure AD B2B）などでゲストIDを発行。招待メールで取引先担当者が登録し、自社IdPのMFAを使用します。取引先はIDを持つだけで構いません。

適用例：小売業→中小取引先（数百社）、建設業→協力会社

パターンC: 取引先専用ポータル（大量低頻度アクセス向け）

EDIポータル・受発注システムに専用の軽量認証を提供。取引先コード+ワンタイムコードや、取引先代表者メールで認証します。ITリテラシーが低い中小取引先向け。

適用例：大手スーパーの食品取引先（数千社・中小零細含む）

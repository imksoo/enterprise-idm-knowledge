サポート終了する製品と影響範囲

🖥️ Windows Server 2019

EOL：2029年1月9日

影響：ドメインコントローラー（AD）として利用している場合、セキュリティパッチが出なくなる

対応：Windows Server 2025への移行（または後継ADクラウド化）

🔧 MIM 2016 SP2

EOL：2029年1月9日

重要：後継製品が存在しない。Microsoftが機能をEntra IDに移行する方針

対応：Entra ID Governance、SailPoint、Saviynt等への全面移行が必要

📋 ADFS 3.0（WS2016同梱）

EOL：2027年1月12日（先に終了！）

影響：ADFSでSSO提供している場合、2027年までに移行が必要

対応：Entra ID SSO/Entra External IDへの移行

なぜ「2年あるから大丈夫」ではないのか

IT刷新プロジェクトに必要な時間の現実
フェーズ作業内容期間目安
① 現状調査・要件定義現在のID管理の棚卸し、移行要件の整理3〜4ヶ月
② 製品選定・調達RFP作成、ベンダー選定、契約2〜3ヶ月
③ 設計・構築新システムの設計・構築・テスト4〜6ヶ月
④ 移行・並行運用全ユーザーの移行・動作確認3〜4ヶ月
⑤ 安定化移行後の問題対応・チューニング2〜3ヶ月
合計最低所要期間18〜20ヶ月
逆算すると：2029年1月のEOLに間に合わせるには、遅くとも2027年6月には移行完了が必要。つまり2026年中に意思決定・計画開始が必須です。
